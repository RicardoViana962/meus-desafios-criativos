# meus-desafios-criativos
React e DIO Formula Perfeita

Tecnologias: React, TypeScript, Vite, Tailwind CSS, React Router, React Hooks, Google Gemini API, localStorage, npm e Git/GitHub.

Essa combinação permite construir uma aplicação Front-End moderna, responsiva e interativa, com persistência de dados e recursos de IA Generativa.

Essa combinação sustenta uma aplicação Front-End moderna, e 
o papel de cada tecnologia na arquitetura do Planej.ai fica mais claro quando relacionado ao fluxo de dados desde o formulário até o histórico.
